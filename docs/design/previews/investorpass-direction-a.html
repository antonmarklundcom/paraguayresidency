Paraguay Investor Pass — Direction A, “The Record”

Homepage design preview. Document logic: hairlines, ruled grid, monospaced data, one accent. Desktop 1440 above, mobile 390 below.

Desktop — 1440 × auto
Mobile — 390 × 844 (scrolls)

Designer’s note. Palette is deliberately not gold-on-black. Ground #0B0D11 ink, type #ECE7DC, hairlines #23272E, and a single accent — #E8DCC4 bone — used only for the primary CTA, the verified marker and row hover. Luxury comes from paper stock and type, not from metallics. One light interruption (#F2EDE3) at “Who files this” so the page has a breath and the team section is impossible to skip.

Type: Instrument Serif for display (high contrast, set very large, tight), Inter for body, IBM Plex Mono for every label, numeral and state chip.

The idea to judge: the status strip directly under the hero. Four figures an investor came to find, each showing its evidence state instead of a number we can’t stand behind. Competitors print confident numbers that contradict each other; this page makes not-knowing the proof of rigour.

CRO: primary action repeated at four depths (bar, hero, route rows, form) but only one primary per screen; hero answers what/who/what-next above the fold at both widths; the route table gives each row its own CTA so a self-identifying investor can skip the page; the form is four fields with “what happens next” under the button; sticky bottom bar on mobile.
