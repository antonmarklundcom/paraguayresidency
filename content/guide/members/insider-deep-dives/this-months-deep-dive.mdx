The single most common Insider question is some version of "is my timeline normal?" This deep
dive is the honest answer, expanded past what the main guide's timeline chapter has room for.

**What a normal delay looks like:** processing sitting still for a stretch with no request for
more information. This is the default state of a government queue, not a sign of a problem —
chapter 5 already tells you this, and it is worth repeating because it is the thing people worry
about most.

**What an actual problem looks like:** a specific request for a missing or corrected document
that goes unanswered, or a case that has clearly moved past the range we quote and has an
identifiable cause when we ask about it — a legalisation done incorrectly, a name mismatch
between documents, or a police certificate that expired mid-process.

**What to actually do:** if you are inside the normal range, the right move is usually nothing —
following up repeatedly does not speed up a government office and can occasionally slow things
down by adding noise to a queue. If you are past it, ask us to check rather than guessing; we can
usually tell you within a day whether it is a real hold-up or ordinary variance.
